Tabbed key-values — the moods' dashboard property card: a title with a status chip, tabs, and key · value rows

header — heading2 title (a card's title is the theme's h2, as the moods draw it) and a small status `Badge` (with the dot) in a row, space between

rows — a `List` of `ListItem`s, each a row: quiet key · strong value, space between, baseline
